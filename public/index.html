API Flask de ejemplo

InicioManualRepositorio

Una API pequeña para aprender a validar peticiones y probar respuestas.

Arranque local

python -m venv .venv
# Usa el intérprete de .venv en los comandos siguientes
python -m pip install -r requirements.txt
python index.py

Abre http://127.0.0.1:5000/. El servicio no se ejecuta dentro de esta página estática.

Contrato HTTP

  • GET /: saludo HTML original.
  • GET /health: estado JSON.
  • POST /api/sumar: recibe {"a": 2, "b": 3} y devuelve {"resultado": 5}.

Rechaza valores ausentes, booleanos, texto y números no finitos. No hay base de datos, usuarios ni autenticación de producción.
